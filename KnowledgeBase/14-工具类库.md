# 模块 14：工具类库

## 概述
`Game/Utility/` 提供资源路径、字符串、JSON、Web 请求等通用工具；`Game/Debugger/` 提供调试窗口扩展。

## 工具类（`Game/Utility/`）
| 类 | 职责 | 关键 API |
| --- | --- | --- |
| `AssetUtility.cs` | 资源路径统一收口（partial，生成代码可扩展） | `GetFontAsset`/`GetSceneAsset`/`GetMusicAsset`/`GetSoundAsset`/`GetPrefabAsset`/`GetEntityAsset`/`GetUIEntityAsset`/`GetUIFormAsset`/`GetLocalizationAsset`/`GetShaderAsset`/`GetShaderShaderVariantsAsset` |
| `StringUtility.cs` | 字符串工具 | 格式/拼接/常用判断 |
| `NewtonsoftJsonHelper.cs` | Json.NET 序列化辅助 | `SerializeObject`/`DeserializeObject` |
| `WebUtility.cs` | Web 请求工具 | 简单 GET/POST（内部走 UGF WebRequest） |
| `ZStringTextHelper.cs` | ZString 高性能字符串拼接（零 GC） | 替换 `string.Format` |
| `HyperlinkLogHelper.cs` | 日志超链接辅助 | 点击日志跳转代码 |

### 资源路径约定（AssetUtility）
| 类型 | 路径模板 |
| --- | --- |
| 字体 | `Assets/Res/Font/{name}.otf` |
| 场景 | `Assets/Res/Scene/{name}.unity` |
| 音乐 | `Assets/Res/Music/{name}.mp3` |
| 音效 | `Assets/Res/Sound/{name}.wav` |
| 预制体 | `Assets/Res/Prefab/{name}.prefab` |
| 实体 | `Assets/Res/Entity/{name}.prefab` |
| UI 实体 | `Assets/Res/UI/UIEntity/{name}.prefab` |
| UI 窗体 | `Assets/Res/UI/UIForm/{name}.prefab` |
| 本地化 | `Assets/Res/Localization/{Language}/{name}` |

> 生成代码 `Game/Generate/Localization/AssetUtility.Localization.cs` 也会扩展 AssetUtility，自动生成语言常量。

### 示例
```csharp
string scenePath = AssetUtility.GetSceneAsset("Main"); // Assets/Res/Scene/Main.unity
string json = NewtonsoftJsonHelper.SerializeObject(obj);
ZStringTextHelper.Format("玩家 {0} 得分 {1}", name, score); // 零 GC
```

## 调试窗口（`Game/Debugger/ToolDebuggerWindow.cs`）
- 实现 UGF `IDebuggerWindow`，注册进 UGF Debugger 组件即可在主调试面板出现自定义 Tab。
```csharp
public class ToolDebuggerWindow : IDebuggerWindow
{
    public void Initialize(params object[] args) { }
    public void Shutdown() { }
    public void OnEnter() { }
    public void OnLeave() { }
    public void OnUpdate(float elapseSeconds, float realElapseSeconds) { }
    public void OnDraw() { /* IMGUI 绘制 */ }
}
```
- 注册位置：`GameEntry.Debugger`（`GameEntry.Builtin.cs` 中注册的 DebuggerComponent）。
- 用途示例：运行时快捷开关、查看隐藏信息、模拟断网等调试功能。

## 设计要点
- 所有资源路径集中在 `AssetUtility`，改目录只需改一处；自动生成代码会追加新类别。
- 高性能路径（ZString）与业务路径（string.Format）按需选择。
