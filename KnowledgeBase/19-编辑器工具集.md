# 模块 19：编辑器工具集

## 概述
`Game/Editor/` 汇集 GDK 的全局编辑器工具：构建（Build）、模式宏（DefineSymbol）、代码生成（CodeCreator）、Toolbar 快捷按钮、资源规则、包更新等。

## 工具清单
| 工具 | 位置 | 职责 |
| --- | --- | --- |
| 构建工具 | `Editor/Build/`（`BuildToolEditor.cs`、`BuildHelper`） | 一键打包（见模块 20） |
| 宏切换 | `Editor/DefineSymbol/DefineSymbolTool.cs` | 模式切换（见模块 02） |
| 代码生成 | `Editor/CodeCreator/`（ET 下 `Game/ET/Editor/CodeCreator/`） | Component/UIForm/UIWidget/Entity 模板生成 |
| Toolbar | `Editor/ToolBar/`（SceneToolBar、ExcelExporterToolBar、LauncherSceneToolBar、OpenFolderToolBar、FocusFolderToolBar 等） | 主工具栏快捷按钮 |
| 资源规则 | `ResourceRuleTool` | 激活 ET/GameHot 资源收集规则 |
| 包更新 | `Editor/Tool/PackageUpdateTool.cs` | UPM 包更新 |
| link.xml | `LinkXMLHelper` | 裁剪配置维护 |

## ET 代码生成工具（ET/Code Creator）
- 菜单 `ET/Code Creator`，反射扫描实现 `ICodeCreator` 的类。
- 内置 4 类生成器：
  | 生成器 | 生成内容 |
  | --- | --- |
  | `DefaultComponentSystem` | Component + System（Client/Server/Share/View 四路径可选） |
  | `UIForm` | UIForm + System + Mono，并创建 prefab |
  | `UIWidget` | UIWidget + System + Mono（不建 prefab） |
  | `UGFEntity` | GFEntity + System + Mono（不建 prefab） |
- 模板在 `Unity/Assets/Res/Editor/ET/Config/*.txt`，用 `#NAME#`/`#NAMESPACE#` 占位符替换。
- 输入 PascalCase 名（不填后缀），拒绝覆盖已有文件。

## 自定义 Toolbar
- 基于 `me.xw.toolbarextension` 包。
- 静态无参方法加 `[Toolbar(OnGUISide.Left/Right, priority)]` 特性即注册到 Unity 主工具栏。
```csharp
public class SceneToolBar
{
    [Toolbar(OnGUISide.Right, 1)]
    private static void OpenLauncherScene()
    {
        UnityEditor.SceneManagement.EditorSceneManager.OpenScene("Assets/Launcher.unity");
    }

    [Toolbar(OnGUISide.Right, 2)]
    private static void ReloadExcel()
    {
        // 触发导表
    }
}
```
- 官方文档：`Book/自定义Toolbar.md`。

## 一键构建入口
- 菜单/窗口 `Game/Build Tool Editor`（BuildToolEditor）。
- 支持：BuildPkg（全流程）、仅建资源、刷新 Windows64 StreamingAssets、Open Pkg Folder、Build Kit.sln。
- 详情见模块 20。

## 设计要点
- 所有工具通过 Unity 菜单（`Game/`）或主工具栏（Toolbar 特性）暴露，无需记忆命令。
- 代码生成采用"拒绝覆盖"策略，安全可重复执行；生成物集中在 Generate 目录。
