# 模块 23：静态分析与代码生成器

## 概述
`Share/Analyzer`（Roslyn 分析器，约 19 条 ET 规范规则）+ `Share/SourceGenerator`（增量代码生成器）由 `Kit.sln` 构建后供 Unity 使用：Unity 侧 `OnGenerateCSProjectProcessor.cs` 在生成项目时注入 `ProjectReference OutputItemType="Analyzer"`，编写代码时即得编译期检查与自动补全。

## Analyzer 规则分类（`Share/Analyzer/`）
> 入口：`AnalyzerGlobalSetting.cs`；规则全集：`Config/DiagnosticRules.cs`；工具类：`Extension/AnalyzerHelper.cs`；CodeFix：`CodeFixer/EntitySystemCodeFixProvider.cs`。

### 实体/组件规范
| 规则 | 检查内容 |
| --- | --- |
| `EntityComponentAnalyzer`(ET0007) | 组件类型须用 `ComponentOf` 标记父实体 |
| `AddChildTypeAnalyzer`(ET0001) | `AddChild` 参数须符合 `ChildOf` 约束 |
| `EntityClassDeclarationAnalyzer`(ET0003) | 禁止多层实体继承 |
| `EntityCannotDeclareGenericType`(ET0029) | 禁止泛型实体 |
| `EntityComponentChildAnalyzer`(ET0028) | 禁止同时标记 Component + Child |
| `DisableNewAnalyzer`(ET0031) | `DisableNew` 类禁止 new |
| `EntityHashCodeAnalyzer`(ET0027) | 实体类 HashCode 唯一 |
| `DisableNormalClassDeclaratonInModelAssembly`(ET0032) | Model 程序集仅允许实体类（`[EnableClass]` 豁免） |

### 字段/成员
| 规则 | 检查内容 |
| --- | --- |
| `EntityFiledAccessAnalyzer`(ET0002)+CodeFixer | 实体类禁直接访问 Child/Component |
| `EntityFieldDeclarationInEntityAnalyzer`(ET0020) | 实体字段改用 `EntityRef` |
| `StaticFieldDeclarationAnalyzer`(ET0015) | static 字段须打标签 |
| `LSEntityFloatMemberAnalyzer`(ET0023) | LS 实体禁浮点字段（帧同步确定性） |

### System/异步
| 规则 | 检查内容 |
| --- | --- |
| `EntitySystemAnalyzer`(ET0024) | 生命周期函数须已生成 |
| `EntitySystemMethodNeedSystemOfAttrAnalyzer`(ET0025) | EntitySystem 标签须在 EntitySystemOf 静态类中 |
| `ETTaskAnalyzer`(ET0008/0009) | async/非 async 中须 await 或 `.Forget()` |
| `AsyncMethodReturnTypeAnalyzer`(ET0021) | 禁 async void，用 UniTaskVoid |
| `ETCancellationTokenAnalyzer`(ET0016-0019) | await 后须查 `IsCancel`、传同一 token、禁默认值/null |

### 消息/其他
| 规则 | 检查内容 |
| --- | --- |
| `NetMessageAnalyzer`(ET0030) | 消息类禁实体字段 |
| `ClientClassInServerAnalyzer`(ET0022) | Server 程序集禁引 `ET.Client` |
| `UniqueIdAnalyzer`(ET0011/12) | Id 区间/去重 |
| `StaticClassCircularDependency`(ET0013) | 静态类循环依赖 |
| `FiberLogAnalyzer`(ET0026) | 实体相关代码须用 Fiber 日志 |

### Custom 扩展（`Custom/Analyzer/`）
禁 Task 只用 UniTask；命名大写/小写/`_` 结尾规范；禁 `UnityEngine.Debug`；禁 `+` / string.Format 拼接。

## SourceGenerator（`Share/SourceGenerator/`）
| 生成器 | 作用 |
| --- | --- |
| `ETSystemGenerator` | 扫描 `[EntitySystem]`/`[MessageHandler]`/`[Event]` 等，按 `AttributeTemplate.cs` 模板生成 `XxxSystem`/`Xxx_Handler` 类 |
| `ETGetComponentGenerator` | 依据 `ComponentOf` 生成强类型 GetComponent 扩展 |
| `ETEntitySerializeFormatterGenerator` | 生成实体序列化/反序列化 Formatter（TBufferWriter/scoped 区分 Model） |
| `ETReactiveSystemGenerator` | `ETReactiveSource`/`Bind` 生成响应式宿主 `ObserveChanges/Reset/Clear` |

## 消费机制
```
Kit.sln 构建 Share.Analyzer.csproj / Share.SourceGenerator.csproj
  → Unity/Assets/Scripts/.../Editor/PostProcessor/OnGenerateCSProjectProcessor.cs
  → 生成 .csproj 时注入 ProjectReference OutputItemType="Analyzer"
  → IDE 编译期检查 + 代码生成
```

## 设计要点
- 分析器把 ET 框架约束（ComponentOf/ChildOf/EntityRef/禁用 new 等）变成**编译期强制**，从源头避免错误用法。
- SourceGenerator 把 System/Handler/序列化/响应式绑定等样板代码自动生成，业务只写声明。
- 与 `Book/Entity开发.md`（ETEntity 规范）配套使用。
