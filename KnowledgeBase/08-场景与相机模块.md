# 模块 08：场景与相机模块

## 概述
场景与相机均以配置表（`DTScene`/`DRScene`）为数据源，通过 `GameEntry.Scene`、`GameEntry.Camera` 访问，提供"按 Id 操作、自动解析资源路径"的封装。

## 场景模块（`Game/Scene/`）
### 核心类
| 文件 | 内容 |
| --- | --- |
| `SceneExtension.cs` | 同步扩展：按 sceneId 判断/加载场景 |
| `SceneExtension.Awaitable.cs` | UniTask 异步版本 |

### 关键 API（SceneExtension）
```csharp
// 按 sceneId（DRScene 表）查询状态
bool loading = GameEntry.Scene.SceneIsLoading(sceneId);
bool loaded  = GameEntry.Scene.SceneIsLoaded(sceneId);
bool canLoad = GameEntry.Scene.CanLoadScene(sceneId); // 未在加载且已加载

// 加载/卸载场景（异步）
await GameEntry.Scene.LoadSceneAsync(sceneId, userData);
await GameEntry.Scene.UnloadSceneAsync(sceneId, userData);

// 直接加载（资源名）
GameEntry.Scene.LoadScene(assetName, userData);
```
- 资源路径解析：`AssetUtility.GetSceneAsset(assetName)` → `Assets/Res/Scene/{name}.unity`。
- 场景数据表 `DRScene`：字段含 `AssetName` 等，配表位置 `Design/Excel/*/Datas/Game/Scene.xlsx`。

## 相机模块（`Game/Camera/`）
### 核心类
| 文件 | 内容 |
| --- | --- |
| `CameraComponent.cs` | 相机组件（挂 GameEntry），管理 UI 相机与场景相机 |
| `SceneCamera.cs` | 场景相机逻辑（可被场景内相机替换） |
| `SceneCameraEnableEventArgs.cs` / `SceneCameraDisableEventArgs.cs` | 场景相机启用/禁用事件参数 |

### 关键 API（CameraComponent）
```csharp
GameEntry.Camera.UICamera;          // UI 相机（渲染 UI Canvas）
GameEntry.Camera.CurrentSceneCamera; // 当前场景相机

// 切换场景相机
GameEntry.Camera.SetCurrentSceneCamera(camera);
```
- 事件订阅：`GameEntry.Event.Subscribe(SceneCameraEnableEventArgs.EventId, OnSceneCameraEnable)`，场景内相机挂 `SceneCamera` 后通过事件自动接管/交还。
- 使用 URP（`UnityEngine.Rendering.Universal`），支持后处理相机栈。

## 设计要点
- 场景/相机都通过事件解耦：相机组件不直接引用场景逻辑，场景通过事件通知相机切换。
- 所有场景资源统一收口在 `Assets/Res/Scene/`，加载走 GF Resource。
