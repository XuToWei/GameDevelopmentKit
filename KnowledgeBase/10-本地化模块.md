# 模块 10：本地化（多语言）模块

## 概述
本地化基于 UGF Localization 组件扩展，支持 **XML 字典**与 **Luban 表**两种数据源，内置默认字典（Builtin）保证语言切换瞬间可用，编辑器提供预览能力。

## 核心类（`Game/Localization/`）
| 类 | 职责 |
| --- | --- |
| `LocalizationExtension.cs` | `LoadLanguageAsync(Language)` 加载语言：先清空 raw strings → 载入 Builtin 默认字典 → 异步读取 XML 数据 |
| `XmlLocalizationHelper.cs` | 继承 `DefaultLocalizationHelper`，解析 XML 字典（`<Dictionaries><Dictionary>` 结构，按当前语言取节点） |
| `LubanLocalizationHelper.cs` | 从 Luban 导出的本地化表读取（多语言配表方案） |

## 关键 API
```csharp
// 切换语言并加载
await GameEntry.Localization.LoadLanguageAsync(Language.English);

// 当前语言
GameEntry.Localization.Language;

// 取字符串
GameEntry.Localization.GetString(key);
```

## Builtin 默认字典（`Game/Builtin/BuiltinLocalizationDictionary.cs`）
- `BuiltinComponent.m_LocalizationDictionaries`：编辑器配置的多语言默认字典数组。
- `BuiltinComponent.InitDefaultDictionary(language)`：切换语言时先把默认字典写入 raw strings，保证核心 UI（如"确定/取消"）立即可用，XML 加载完成后由外部数据覆盖/补充。
- 警告：key 无效或重复会 `Log.Warning` 并中止（保持幂等）。

## 资源路径
```csharp
AssetUtility.GetLocalizationAsset(assetName)
// Assets/Res/Localization/{Language}/{assetName}
```

## 数据流（切换语言）
```
LoadLanguageAsync(language)
 ├─ RemoveAllRawStrings()          # 清空旧数据
 ├─ Builtin.InitDefaultDictionary  # 写入内置默认字典（立即生效）
 └─ ReadDataAsync(XML)             # 异步加载完整字典（XmlLocalizationHelper 解析）
```
