# 模块 11：事件与日志模块

## 事件模块（`Game/Event/EventExtension.cs`）
### 概述
基于 UGF `EventComponent` 的全局事件总线。GF 事件按 `int EventId`（通常是事件类 GetHashCode）订阅/广播，本模块补充**安全退订**扩展。

### 关键 API
```csharp
// 安全退订：仅当确实订阅过才退订，避免重复退订异常
GameEntry.Event.TryUnsubscribe(eventId, handler);

// 等价手动写法
if (GameEntry.Event.Check(eventId, handler))
    GameEntry.Event.Unsubscribe(eventId, handler);
```

### 自定义事件写法（GF 标准）
```csharp
public class ShopItemUpdatedEventArgs : GameEventArgs
{
    private static readonly int s_EventId = typeof(ShopItemUpdatedEventArgs).GetHashCode();
    public override int Id => s_EventId;
    public int ItemId { get; private set; }

    public static ShopItemUpdatedEventArgs Create(int itemId)
    {
        var e = ReferencePool.Acquire<ShopItemUpdatedEventArgs>();
        e.ItemId = itemId;
        return e;
    }
    public override void Clear() { ItemId = 0; }
}
```

### 设计要点
- 事件参数继承 `GameEventArgs` 且走 ReferencePool，发布方负责 `Create`，系统自动 `Clear` 回收。
- 建议配合 `EventContainer`（模块 05）让窗体生命周期自动管理订阅，避免泄漏。
- ET 模式另有独立事件系统（见模块 16 动态事件），两者不混用。

## 日志模块（`Game/Log/`）
### 概述
在 UGF `Log` 基础上提供**按模块着色**的分类日志，便于控制台快速区分来源。

### 核心类
| 类 | 说明 |
| --- | --- |
| `LogWithTag` | 带彩色标签的日志封装（包裹 UGF Log） |
| `Log.cs`（`GLog`） | 静态分类日志入口 |

### 内置分类标签（GLog）
| 属性 | 颜色 | 用途 |
| --- | --- | --- |
| `GLog.Entity` | 红 `#ff0000` | 实体 |
| `GLog.Game` | 蓝 `#0066ff` | 游戏逻辑 |
| `GLog.Procedure` | 绿 `#00ff00` | 流程 |
| `GLog.Resource` | 橙 `#ff6600` | 资源 |
| `GLog.Scene` | 紫 `#9900ff` | 场景 |
| `GLog.Sound` | 青 `#00ffff` | 音频 |
| `GLog.UI` | 黄 `#ffff00` | UI |

```csharp
GLog.UI.Info("打开窗体：{0}", name);
GLog.Resource.Warning("资源未找到：{0}", path);
```

### 设计要点
- 标签带 Unity Rich Text 颜色，Console 中高亮可读。
- 全局 `Log` 仍可直接用（无标签），`HyperlinkLogHelper`（`Game/Utility/`）支持点击跳转代码位置。
