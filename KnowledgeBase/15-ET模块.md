# 模块 15：ET 模块（Loader 与四程序集）

## 概述
ET 模式引入完整 ET 8.1 框架（`Library/ET/Core/` 约 463 个 cs），与 UGF 通过适配层（`Game/ET/Loader/UGF/`）打通。业务代码按 Model/Hotfix/ModelView/HotfixView 四程序集组织（`Game/ET/Code/`，约 510 个 cs）。

## 加载层（`Game/ET/Loader/`）
| 类 | 职责 |
| --- | --- |
| `Init.cs` | Mono 入口：`Awake` SetRootView；`Start` 注册 World 单例（Logger/TimeInfo/FiberManager/Config/CodeLoader）→ `await CodeLoader.StartAsync` → 挂 `Runner` 驱动 Update |
| `CodeLoader.cs` | 按 `EnableHotfix` 与 CodeBytesMode 加载程序集：编辑器直接用 Unity dll，否则从 AssetBundle 读 `.dll.bytes`；注册 `CodeTypes`；反射调 `ET.Entry.Start()` |
| `GlobalComponent` | 全局单例容器 |
| `UnityLogger` / `UnityTimeNow` | 日志/时间适配 Unity |
| `ConfigReader` | ET 配置读取适配 |

## GF 适配层（`Game/ET/Loader/UGF/`）
| 类 | 职责 |
| --- | --- |
| `UGFComponent` | 挂 Scene，封装 GF 资源/场景/实体/UI 能力 |
| `UGFSystemSingleton` | 扫描注册 System（把 GF 生命周期转发给 ET System） |
| `UGFHelper` | 静态工具 |
| `UGFEntity` / `UGFUIForm` / `UGFUIWidget` | ET 实体（持有 `View`/`UGFMono`） |
| `ETMonoUGFEntity : AEntity` | Mono 桥接：把 GF Show/Hide/Update/Attach 生命周期转给 ET |
| `AETMonoUGFEntity` / `AETMonoUGFUIForm` / `AETMonoUGFUIWidget` | 各类 Mono 基类 |

## 四程序集组织（`Game/ET/Code/`）
| 程序集 | 示例文件 | 内容 |
| --- | --- | --- |
| Model | `Model/Share/Module/DynamicEvent/DynamicEventComponent.cs` | 纯定义（`noEngineReferences=true`），共享数据/模块 |
| Hotfix | `Hotfix/Share/LockStep/RoomSystem.cs` | System 与业务逻辑 |
| ModelView | `ModelView/Client/LockStep/LSUnitView.cs` | 客户端视图模型（引用 UnityEngine/GF） |
| HotfixView | `HotfixView/Client/Demo/UI/UILogin/UIFormLoginComponentSystem.cs` | 视图 System |

## 实体与生命周期
- `Entity` 基类在 `Library/ET/Core/Runtime/Entity/Entity.cs`。
- 系统式生命周期：`IAwake/IUpdate/IDestroy` + `EntitySystemSingleton` 调度。
- `UNITY_ET_VIEW` 下自动生成调试 `viewGO` + `ComponentView`（挂 Init 节点）。
- 运行时绑定：`UGFEntity<T>.View = UGFMono.GetComponent<T>()`；`ETMonoUGFEntity` 把 GF 回调转给 UGF 系统，再分派到 `[UGFEntitySystem]` 标记的 System。

## 关键可复用类（Top 10）
1. `Entity` 实体基类
2. `World` 单例容器
3. `EventSystem` 事件中枢
4. `EntitySystemSingleton` 系统调度
5. `Scene` / `SceneType`（含 `HasSameFlag` 场景类型判断）
6. `FiberManager` 纤程管理
7. `ObjectPool` 对象池
8. `ConfigComponent` 配置组件
9. `UGFComponent` GF 能力封装
10. `DynamicEventComponent` / `ADynamicEvent` 动态事件（见模块 16）
