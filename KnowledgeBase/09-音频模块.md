# 模块 09：音频模块

## 概述
音频模块基于 UGF Sound 组件封装，以配置表（`DRMusic`/`DRSound`）为数据源，提供音乐（Music）与音效（Sound/UI Sound）两类 API，统一处理淡入淡出、优先级、空间混合与资源路径。

## 核心类（`Game/Sound/SoundExtension.cs`）
| API | 说明 |
| --- | --- |
| `PlayMusic(this SoundComponent, int musicId, object userData = null)` | 播放音乐：自动停掉上一首；从 `DTMusic` 表读配置；循环、优先级 64、淡入 1s、SpatialBlend=0 |
| `StopMusic(this SoundComponent)` | 停止音乐（带 1s 淡出），单例管理 `s_MusicSerialId` |
| `PlaySound(this SoundComponent, int soundId, AEntity bindingAEntity = null, object userData = null)` | 播放音效：从 `DTSound` 表读配置，可绑定实体（随实体位置/生命周期） |
| `PlayUISound(this SoundComponent, int uiSoundId, object userData = null)` | 播放 UI 音效 |
| `StopSound(serialId, fadeOut)` | 按 ID 停止（带淡出） |

## 典型用法
```csharp
// 播放背景音乐（自动切换）
GameEntry.Sound.PlayMusic(DRMusicId.BgmMain);

// 停止音乐
GameEntry.Sound.StopMusic();

// 播放音效（绑定到实体，自动跟随位置）
GameEntry.Sound.PlaySound(DRSoundId.Attack, bindingAEntity: playerEntity);

// UI 按钮音效（全局统一挂接）
ExButton.AllButtonOnPointerDownEvent += () => GameEntry.Sound.PlayUISound(1000);
```

## 数据表
| 表 | 用途 | 关键字段 |
| --- | --- | --- |
| `DRMusic`（DTMusic） | 背景音乐配置 | AssetName 等 |
| `DRSound`（DTSound） | 音效配置 | AssetName、绑定实体等 |

## 资源路径约定
```csharp
AssetUtility.GetMusicAsset(name)  // Assets/Res/Music/{name}.mp3
AssetUtility.GetSoundAsset(name)  // Assets/Res/Sound/{name}.wav
```
优先级常量（`Constant.AssetPriority`）：MusicAsset=20、SoundAsset=30、UISoundAsset=30。

## 设计要点
- 音乐单例管理：重复调用 PlayMusic 自动淡出旧曲，避免叠播。
- 音效支持绑定 `AEntity`，实体销毁时音效自动停止，适合攻击/脚步等位置音。
- 所有音频行为通过表驱动，策划可配，无需改代码。
