# 模块 26：服务端运维组件（Aspire/FileServer/NLog/管理后台）

## 概述
服务端配套的运维组件分布在 `Share/` 与 `Config/`：**Aspire** 负责进程编排、**FileServer** 提供热更资源下载、**NLog** 负责日志落盘、**Admin 管理后台**提供可视化运维界面。这些组件与模块 21 的 DotNet 服务端配合构成完整运维体系。

## Aspire 进程编排（Share/Aspire/）
- 基于 .NET Aspire 的云原生编排器。
- 读取 Luban 配置，逐进程 `AddExecutable` 启动 `App.dll`，传入 `Process/SceneName/StartConfig` 参数。
- 通过 OTLP 上报遥测（日志/指标/链路）。
- 用途：本地/测试环境一键拉起整套服务端拓扑（多进程）。

## FileServer 文件服务器（Share/FileServer/）
- Kestrel 静态文件服务器，默认端口 8088。
- 提供目录浏览，服务 `Bundle/Version` 热更资源的下载。
- 用途：客户端热更新版本检查与资源下载的本地/内网源（配合模块 20 一键打包的"本地资源服务器"）。

## NLog 日志配置（Config/NLog/）
- 服务端日志：分 Debug/Info/Warn/Error 四级，按小时落盘到 `../Logs/`。
- 异步 target，避免阻塞游戏线程。
- 对应 ET 的 Logger 适配（`DotNet/Loader/` 注册）。

## Admin 管理后台（服务端）
> 详见模块 21。
- 独立 Fiber（AppType=Admin），`AdminComponent` 内置 ASP.NET Core Blazor Server + MudBlazor。
- 默认端口 5200；LiteDB 存储。
- 通过 Actor 消息（`Admin2S_*`/`Admin2Agent_*`）管理服务器：启停、热重载、部署、数据查看。
- 官方文档：`Book/管理后台.md`。

## Agent 部署代理（服务端）
> 详见模块 21。
- 每台机器一个 Agent，`FiberInit_Agent` 启动本机所有非 Agent/Admin 进程。
- 心跳上报 Admin，接收 Admin 指令（启停/热重载/部署）。
- 与 Admin 配合实现"管理后台 → Agent → 目标进程"的运维链路。
