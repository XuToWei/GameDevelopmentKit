# 模块 13：内置窗体与通用 UI

## 概述
内置窗体模块（`Game/Builtin/`）提供**不依赖业务资源、随包编译**的通用 UI：构建信息、更新资源进度、通用对话框、本地化默认字典。它们不属于可热更业务程序集，保证加载阶段（资源未就绪时）也能展示。

## 核心类
| 类 | 职责 |
| --- | --- |
| `BuiltinComponent.cs` | 内置组件（挂 GameEntry，经 `GameEntry.Builtin` 访问）；持有构建信息、本地化字典、更新窗体与对话框模板 |
| `BuiltinBuildInfo.cs` | 构建信息数据结构（版本号、渠道等） |
| `BuiltinDialogForm.cs` / `BuiltinDialogParams.cs` | 通用对话框（标题/内容/按钮回调）与参数 |
| `BuiltinUpdateResourceForm.cs` | 资源更新进度窗体（下载进度条） |
| `BuiltinLocalizationDictionary.cs` | 内置多语言字典（`Language` + `Dictionary<string,string>`） |
| `BaseBuiltinForm.cs` | 内置窗体基类 |
| `BuiltinExtension.cs` | 内置扩展方法 |

## 关键 API
```csharp
// 构建信息（Debugger 激活时用 Debug 版，否则 Release 版）
GameEntry.Builtin.BuildInfo; // => BuiltinBuildInfo

// 打开通用对话框
GameEntry.Builtin.OpenDialogForm(BuiltinDialogParams.Create()
    .SetTitle("提示")
    .SetContent("确定要退出吗？")
    .SetButtonText("取消", "确定")
    .SetOnClickConfirm(() => { /* ... */ }));

// 内置默认字典初始化（语言切换时调用）
GameEntry.Builtin.InitDefaultDictionary(Language.ChineseSimplified);
```

## 构建信息（BuiltinBuildInfo）
- 编辑器可配 Release/Debug 两套（`m_BuildInfoRelease` / `m_BuildInfoDebug`）。
- 展示逻辑：`GameEntry.Debugger.ActiveWindow ? Debug版 : Release版`，方便内网调试。

## 更新资源窗体（BuiltinUpdateResourceForm）
- 模板由 `BuiltinComponent.m_UpdateResourceFormTemplate` 配置。
- 用于 `ProcedureUpdateResources` 阶段展示下载进度，资源系统未就绪时仍可显示。

## 对话框（BuiltinDialogForm）
- 模板 `m_DialogFormTemplate`，通过 `Instantiate` 创建（非 GF UIForm，纯 GameObject 实例），可脱离 UIForm 系统在任何阶段使用。
- 参数支持：标题、内容、确认/取消文案、点击回调、可定制按钮。

## 设计要点
- 内置窗体不走资源加载，避免"先有资源才能加载资源"的循环依赖。
- 对话框采用模板实例化，使用简单且不影响 UIForm 流程。
- 本地化字典内置保证语言数据就绪前 UI 文案可用（详见模块 10）。
