# 模块 04：UI 窗体体系

## 概述
UI 层基于 UGF 的 UIForm/UIWidget 体系扩展，形成 `AUIForm → AExUIForm` 与 `AUIWidget → AExUIWidget` 两层基类，配合四个容器（UIWidget/Event/Entity/Resource）完成窗体资源管理与生命周期。

## 基类体系（`Game/UI/Common/`）
| 类 | 职责 |
| --- | --- |
| `AUIForm : UIFormLogic` | 同步 Depth 到子 Canvas/Particle 的 sortingOrder；提供 `Close()`、`PlayUISound()` |
| `AExUIForm : AUIForm` | 持有 UIWidget/Event/Entity/Resource 四个容器；自动收集子 `AExUIWidget`；暴露 Open/DynamicOpen/Close UIWidget、Subscribe、ShowEntity、LoadAsset 全套 API；转发 Pause/Cover/Depth 生命周期 |
| `AUIWidget : MonoBehaviour`（`[BindingRoot]`） | UIForm 内可复用组件，生命周期 OnOpen/OnClose/OnPause/OnUpdate |
| `AExUIWidget : AUIWidget` | 可嵌套子 Widget（`m_ParentUIWidget`），提供 `TryOpen/TryClose/DynamicOpen` |
| `ADynamicUIWidgetLoader : MonoBehaviour` | 按 `UIWidgetAssetPath` 异步加载并实例化 AUIWidget（编辑器可指定资源路径） |
| `StarForceUIForm : AHotUIForm` | GameHot 工作流基类（字体/本地化/淡入淡出） |

## UI 扩展 API（`Game/UI/UIExtension.cs` / `UIExtension.Awaitable.cs`）
```csharp
// 同步打开（查表，AllowMultiInstance 校验）
int? serialId = GameEntry.UI.OpenUIForm(UIFormId.TestForm, userData);

// 异步打开（可取消、带进度）
UniTask<UIForm> form = GameEntry.UI.OpenUIFormAsync(uiFormTypeId, userData, ct);

// 查询/关闭
bool isLoading = GameEntry.UI.IsLoadingOrHasUIForm(uiFormTypeId);
GameEntry.UI.TryCloseUIForm(serialId);
```

## 打开流程（GameHot 典型）
```csharp
public class UIFormTest : AExUIForm
{
    // CodeBind 生成的字段：m_CloseButton 等
    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        m_CloseButton.onClick.AddListener(OnClickClose);
    }

    private void OnClickClose()
    {
        Close(); // AUIForm.Close()：自动关闭并回收
    }
}
```
外部打开：
```csharp
GameEntry.UI.OpenUIForm(UIFormId.TestForm, userData);
```

## UI 生命周期
- 窗体：OnInit → OnOpen → OnCover/Pause（被覆盖时）→ OnResume → OnClose → OnRecycle。
- Widget：OnOpen/OnClose/OnPause/OnUpdate。
- `AExUIForm` 会在 OnOpen 自动把子 `AExUIWidget` 收集进 UIWidgetContainer。

## 深度/层级
- `AUIForm.OnDepthChanged` 同步给子 Canvas（Sorting Order）与 ParticleSystem 渲染层，保证特效与 UI 层级一致。
- UI 组（Group）与优先级在打开时通过参数控制。
