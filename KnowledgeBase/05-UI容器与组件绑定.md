# 模块 05：UI 容器与组件绑定

## 概述
`AExUIForm` 内置四个**容器**（`Game/Container/`，全部实现 `IReference`，走 GF ReferencePool 池化），统一管理窗体生命周期内的 UIWidget、事件订阅、实体与资源加载，窗体关闭时统一释放，避免泄漏。

## 四大容器
| 容器 | 管理内容 | 关键 API |
| --- | --- | --- |
| `UIWidgetContainer` | 子 AUIWidget 列表 | `UIWidgets`、`GetAllUIWidgets(list)`、`Add/Remove` |
| `EventContainer` | GF 事件订阅 | `Subscribe(id, handler)`、`Unsubscribe`（自动防重） |
| `EntityContainer` | 实体显示与回收 | `ShowEntity<T>(id, data)`（内部包装 ShowEntitySuccess/Failure 事件，统一回调）、`Clear` 时隐藏全部实体 |
| `ResourceContainer` | 异步资源加载 | `LoadAsset<T>(assetName, onSuccess, onFail, priority, ct)`、版本号 + CancellationToken 管理并发 |

### 示例：容器用法
```csharp
public class UIFormShop : AExUIForm
{
    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        // 订阅事件（窗体关闭自动退订）
        Subscribe(ShopItemUpdatedEventArgs.EventId, OnShopItemUpdated);
        // 加载资源（窗体关闭自动回收）
        LoadAsset<Texture2D>("Assets/Res/UI/xxx.png", tex => { /* ... */ });
        // 显示实体（窗体关闭自动隐藏）
        ShowEntity<ShopItemEntity>(DREntityId.ShopItem, entityData);
    }
}
```

## CodeBind 组件绑定
- 包：`me.xw.codebind`（UPM）。
- 预制体挂 `[MonoBehaviourBinding] partial` 类，`[BindingRoot]` 标记根（如 `AUIWidget`）。
- 编辑器生成 `m_xxx` 序列化字段 + 只读公开属性（见 `RuntimeInspectorForm.Bind.cs`）。
- `GameCodeBindCustomizer` 定制 `m_` 前缀，并为 StateController 额外生成 StateGroup/StateName 常量。

## ReactiveBinding 数据绑定
- 包：`me.xw.reactivebinding`；核心思路：绑定字段 → 生成 observer 类 → 数据变化自动刷新 UI。
- ET 侧由 `ETReactiveSystem` 扫描 Hotfix 生成的 observer 并池化（`IETReactiveObserver`，处理 DllVersion 热更重载）。

## StateController 状态控制
- 包：`me.xw.statecontroller`；按状态组切换 UI 显隐/样式。
```csharp
// 横竖屏切换示例（字段由 CodeBind 自动生成）
RootLayoutStateGroup.CurrentStateName = RootLayoutStateName.Horizontal;
```

## LoopScrollRect 列表
- `ExLoopVerticalScrollRect : LoopVerticalScrollRect`：内置对象池，仅需设 `itemRenderer` 与 `numItems`。
- `ETLoopVerticalScrollRect`：item 若是 `AETMonoUGFUIWidget`，自动 `AddChildUIWidget` + `TryDynamicOpen`，回收自动关闭。
